How this works

Your password is run through PBKDF2 (SHA-256, 600,000 iterations) together with a random salt to derive two independent secrets: an AES-256-GCM encryption key, and a seed for a password-only pixel-shuffle. The message is encrypted with AES-GCM (authenticated, so a wrong password is detected rather than producing garbled output). The salt is stored openly in the first pixels of the image (it isn't secret — its job is to defeat precomputed attacks, not to hide anything). Everything else — the IV, the length, and the ciphertext — is scattered across the remaining pixels' least-significant color bits in an order that only someone with the correct password can reproduce. This code is open source, so per standard cryptographic practice the whole scheme is public; the password is the only secret.

Runs entirely client-side. Save the output as PNG — anything lossy (like re-saving as JPEG) will destroy the hidden data.
